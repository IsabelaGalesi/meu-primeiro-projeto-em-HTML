##Meu Primeiro Projeto em JavaScript

## Sobre o projeto

Este é um projeto acadêmico desenvolvido como introdução à programação em JavaScript, utilizando também HTML e CSS.

O projeto foi desenvolvido e finalizado por mim, em casa, como forma de praticar os conteúdos estudados e explorar, de maneira independente, os primeiros conceitos da linguagem.

## Technologies used

- HTML
- CSS
- JavaScript

## Objetivo

O principal objetivo foi praticar e compreender conceitos iniciais de JavaScript, colocando em prática algumas pequenas funções e interações dentro de uma página web.

Este projeto representa uma das minhas primeiras experiências com a linguagem e faz parte do meu processo de aprendizado em programação.


## learnings

Durante o desenvolvimento, pude praticar:

- Estruturação de páginas com HTML;
- Estilização com CSS;
- Conceitos básicos de JavaScript;
- Criação e utilização de funções;
- Interações e comportamentos básicos em uma página web.

## Próximos passos

Este projeto é um ponto de partida. Pretendo continuar estudando JavaScript e, futuramente, aprimorar meus conhecimentos e desenvolver projetos mais completos e elaborados.
