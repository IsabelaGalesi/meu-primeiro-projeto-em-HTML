Você sabe a diferença entre JavaScript, HTML e CSS?

° HTML - Estrutura do site (textos, botões, imagens).
° CSS - Deixa o site bonito (cores, fontes, tamanhos, layout).
° JavaScript - Dá a interatividade e comportamento ao site (cliques, animações, cálculos etc.)
